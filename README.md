# 육아나우 (kr-baby-now)

내 주변에서 지금 진료 중인 소아청소년과·산부인과(야간·주말·공휴일·국가예방접종), 산후조리원, 놀이터, 실내놀이터·키즈카페, 아이돌봄 기관, (부산) 어린이집·수유실을 지도에서 찾는다.

- 배포: https://kr-baby-now.vercel.app
- 런타임 data.go.kr 호출 없음: `data/layers/*.json` 정적 스냅샷을 빌드 때 `public/layers/` 로 복사하고 브라우저가 거리정렬·필터.
- 갱신: `npm run collect` (= `scripts/collect.py` + `scripts/enrich.py`) → 커밋 → 배포. env `DATA_GO_KR_KEY`(로그인 계정 인코딩 키 verbatim).

| 레이어 | 출처 |
|---|---|
| 소아청소년과·산부인과 | 국립중앙의료원 전국 병·의원 찾기(QD=D002/D011) + 질병관리청 어린이 국가예방접종 위탁의료기관(이름+시군구 조인) |
| 산후조리원 | 행정안전부 산후조리업(EPSG:5174→WGS84, 영업중만) |
| 놀이터·실내놀이터 | 행정안전부 전국어린이놀이시설(설치장소로 공개/유료실내 분리, 아파트·유치원·학교 제외) |
| 아이돌봄 기관 | 한국건강가정진흥원 |
| 부산 어린이집·수유실 | 부산광역시 |
